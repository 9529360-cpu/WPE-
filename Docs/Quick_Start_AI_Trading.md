## 🐛 常见问题

### Q1：启动后没有信号生成？

**原因**：市场波动较小，AI 信心度低

**解决方案**：
1. 等待 5-10 分钟（AI 每 30 秒分析一次）
2. 降低信心度阈值（见上方"策略优化"）
3. 切换到波动较大的交易对

---

### Q2：模拟账户盈亏不变？

**原因**：没有开仓（AI 未生成信号）

**解决方案**：
1. 检查信号列表是否有新信号
2. 确认信心度 ≥ 70%
3. 查看日志：`Logs/app-<日期>.log`

---

### Q3：实盘交易失败？

**原因**：
- Binance API Key 权限不足
- 账户余额不足
- 交易对不可用

**解决方案**：
1. 检查 Binance API Key 已启用 `期货交易` 权限
2. 确认账户有足够余额（≥ 100 USDT）
3. 查看日志中的错误信息

---

### Q4：DeepSeek API 额度耗尽？

**原因**：API 调用次数过多，余额不足

**解决方案**：
1. 前往 DeepSeek 控制台充值
2. 建议充值 10-20 元（可使用数百次）
3. 优化 AI 调用频率（在代码中调整）
