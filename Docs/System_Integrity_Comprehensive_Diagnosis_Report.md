```

**问题分析**:

2. ✅ API Key 可能已过期
3. ✅ 网络请求被拦截

- API Key `****4a13` 无效或已过期
- 用户输入的API Key不正确
- 配置未正确保存

**影响范围**:
- ❌ AI智能助手完全无法使用
- ❌ DeepSeek交易Agent失效

- ❌ 市场分析功能受限

**修复方案**:
```
立即修复步骤:
1. 获取有效的 DeepSeek API Key
   - 访问: https://platform.deepseek.com/

2. 正确配置 API Key
   - 打开 [设置] → [API管理]

   - 点击 [测试连接] 验证
   - 点击 [保存] 使配置生效

3. 刷新 AI助手
