### 如果发现问题

#### 问题1: 模块切换后旧模块未停止
**症状**: 切换模块后，旧模块的定时器或订阅仍在运行  
**解决**:
1. 检查 `MainWindow.xaml.cs` 中的 `LoadViewByTag` 方法
2. 确认 `await _currentLifecycle.StopAsync()` 在加载新模块前执行
3. 查看日志确认 StopAsync 是否调用

#### 问题2: 内存持续增长
**症状**: 长时间运行后内存占用持续上升  
**解决**:
1. 检查 EventBus 订阅是否正确取消（查看 `_subscriptions.Clear()`）
2. 检查 CancellationTokenSource 是否正确 Dispose
3. 使用 Visual Studio 性能分析器定位内存泄漏点

#### 问题3: 应用崩溃或卡死
**症状**: 切换模块时应用无响应或崩溃  
**解决**:
1. 查看日志中的异常堆栈
2. 检查 UI 线程是否被阻塞（避免在 StartAsync 中使用同步 I/O）
3. 确认所有 async 方法正确使用 await
