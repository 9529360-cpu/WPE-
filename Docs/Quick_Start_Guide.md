## 🎯 **第一次使用**

### **Step 1: 启动应用**
1. 打开 Visual Studio 2022
2. 按 `F5` 或点击 "启动" 按钮
3. 应用自动打开 **🚀 统一AI仪表盘**

### **Step 2: 检查初始状态**
```
✅ 模拟账户: 100 USDT
✅ 系统状态: 就绪
✅ AI助手: 演示模式
```

### **Step 3: 探索功能**
```
推荐顺序:
1️⃣ 🚀 统一AI仪表盘    - 查看系统概览
2️⃣ 🤖 AI智能助手      - 体验对话交互
3️⃣ 👤 账户资金         - 查看账户详情
4️⃣ 📈 绩效分析         - 查看绩效报告
5️⃣ 🎛️ 策略组合         - 管理交易策略
```

## 🤖 **AI智能助手使用**

### **快速体验**
1. 点击左侧菜单: **🤖 AI智能助手**
2. 查看欢迎消息
3. 点击快捷操作按钮:
   - 📊 分析当前市场
   - 💹 推荐交易策略
   - ⚠️ 评估风险
   - 📈 查看绩效

### **对话示例**
```
用户: "分析当前市场"
AI助手: "📊 市场分析 (演示)
         当前市场状态:
         • BTC: 震荡向上
         • ETH: 跟随BTC走势
         • 建议: 保持谨慎，小仓位测试"
```

### **启用真实AI** (可选)
1. 获取 DeepSeek API Key
2. 打开: `🛠 系统配置`
3. 配置 API Key
4. 重启应用

## 💰 **账户管理**

### **模拟账户** (默认)
```
初始资金: 100 USDT
账户类型: 模拟账户
交易费用: 0.1%
```

### **升级到真实账户**
```
条件:
✅ 总收益率 > 10%
✅ 夏普比率 > 1.5
✅ 最大回撤 < 20%
✅ 交易次数 > 30 笔
✅ 胜率 > 50%
```

### **查看升级进度**
1. 点击: **👤 账户资金**
2. 查看升级规则列表
3. 点击 "检查升级条件"

---

## 📈 **绩效分析**

### **查看绩效报告**
1. 点击: **📈 绩效分析**
2. 查看关键指标:
   - 总收益率
   - 夏普比率
   - 最大回撤
   - 胜率

### **查看净值曲线**
- 蓝色实线: 净值
- 绿色虚线: 可用余额
- 黄色虚线: 持仓价值

### **切换账户类型**
- 下拉框选择: 模拟账户 / 真实账户
- 点击 "🔄 刷新" 更新数据

---

## 🎛️ **策略管理**

### **查看策略组合**
1. 点击: **🎛️ 策略组合**
2. 查看 4 个预置策略:
   - 均值回归策略
   - 动量突破策略
   - 趋势跟随策略
   - AI智能策略

### **调整策略权重**
1. 移动滑块调整权重
2. 点击 "保存权重"
3. 查看绩效对比

### **启动/停止策略**
- 点击策略卡片的 "▶️ 启动" 按钮
- 点击 "⏹️ 停止" 按钮停止

---

## 🧬 **参数优化**

### **开始优化**
1. 点击: **🧬 参数优化**
2. 配置参数范围:
   - MA短期: 5-20
   - MA长期: 20-60
   - RSI阈值: 20-80
   - 止损比例: 1-5%
3. 选择优化方法: 遗传算法
4. 点击 "▶️ 开始优化"

### **查看优化结果**
- 实时进度条
- 适应度进化曲线
- 最优参数组合
- Top 10 结果列表

## 🔧 **常见问题**

### **Q: 如何开始真实交易？**
A: 
1. 先在模拟账户练习
2. 达到升级条件
3. 升级到真实账户
4. 配置真实 API Key

### **Q: AI助手为什么是演示模式？**
A:
- 默认未配置 DeepSeek API Key
- 配置后可启用真实AI分析
- 演示模式提供模拟响应

### **Q: 如何提高胜率？**
A:
1. 使用参数优化功能
2. 调整策略权重
3. 严格风险控制
4. 参考AI助手建议

### **Q: 数据保存在哪里？**
A:
- 配置: `appsettings.json`
- 数据库: `Data/trading.db` (SQLite)
- 日志: `Logs/` 目录

## 📚 **进阶功能**

### **自定义策略**
1. 点击: **📚 策略库**
2. 查看策略模板
3. 创建自定义策略
4. 添加到策略组合

### **风险控制**
1. 点击: **🧮 风险控制**
2. 配置风险参数:
   - 最大持仓比例
   - 单笔最大损失
   - 日损失限额
   - 止损/止盈

### **预警设置**
1. 点击: **🚨 预警通知**
2. 配置预警条件:
   - 价格预警
   - 盈亏预警
   - 风险预警
3. 启用通知
