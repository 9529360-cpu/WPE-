## 📋 需求分析

### 用户核心需求

1. **并行监测10个热门币种**
   - BTC, ETH, BNB, SOL, ADA, DOGE, MATIC, DOT, AVAX, LINK

2. **单一持仓策略**
   - 同时只持有1个订单
   - 完成（止盈/止损）后再执行下一个
   - 避免多仓位导致爆仓风险

3. **高频剥头皮**
   - 小额盈利即可平仓（0.5-1 USDT净收益）
   - 智能计算手续费和滑点
   - 确保卖出时净盈利

4. **成本智能计算**
   - 入场成本 = 手续费 + 滑点
   - 出场成本 = 手续费 + 滑点
   - 净收益 = 价差 - 入场成本 - 出场成本

5. **信号多样性**
   - 10个币种产生足够多的信号
   - 避免单币种频繁交易
   - 冷却时间：5分钟/币种

## 💰 成本计算详解

### 案例：ETHUSDT 交易

**假设**：
- 入场价格：$2000
- 出场价格：$2005
- 仓位数量：0.025 ETH（50 USDT名义本金）
- 手续费率：Taker 0.04%
- 滑点：0.01%

**计算过程**：

1. **入场成本**：
   ```
   名义本金 = 2000 * 0.025 = 50 USDT
   手续费 = 50 * 0.0004 = 0.02 USDT
   滑点 = 50 * 0.0001 = 0.005 USDT
   入场成本 = 0.02 + 0.005 = 0.025 USDT
   ```

2. **出场成本**：
   ```
   名义本金 = 2005 * 0.025 = 50.125 USDT
   手续费 = 50.125 * 0.0004 = 0.02 USDT
   滑点 = 50.125 * 0.0001 = 0.005 USDT
   出场成本 = 0.02 + 0.005 = 0.025 USDT
   ```

3. **价差收益**：
   ```
   价差 = (2005 - 2000) * 0.025 = 0.125 USDT
   ```

4. **净收益**：
   ```
   净收益 = 0.125 - 0.025 - 0.025 = 0.075 USDT
   ```

**结论**：
- 净收益 0.075 USDT < 0.5 USDT（最小净收益阈值）
- **不平仓**，继续持有等待价格上涨

---

### 何时平仓？

**情况1：止盈**
- 价格涨到 $2040
- 净收益 = (2040 - 2000) * 0.025 - 0.05 = **0.95 USDT** ✅
- **触发平仓**

**情况2：止损**
- 价格跌到 $1960
- 净收益 = (1960 - 2000) * 0.025 - 0.05 = **-1.05 USDT** ❌
- **触发止损平仓**

**情况3：超时**
- 持仓30分钟，价格 $2010
- 净收益 = (2010 - 2000) * 0.025 - 0.05 = **0.2 USDT** < 0.5 USDT
- **超时强制平仓**（接受小亏或小盈）

## 🛡️ 风险控制

### 1. 单一持仓策略
- **目的**：避免多仓位导致爆仓
- **实现**：使用 `_positionLock` 确保同时只有1个持仓
- **效果**：最大风险敞口 = 单笔止损额度（1 USDT）

---

### 2. 冷却时间
- **目的**：避免单币种频繁交易
- **实现**：`_lastTradeTime` 字典记录最后交易时间
- **参数**：5分钟/币种
- **效果**：单币种最多每5分钟交易1次

---

### 3. 日亏损限制
- **目的**：防止单日巨额亏损
- **实现**：检查 `account.TodayPnL` 是否超过阈值
- **参数**：5% 账户资金
- **效果**：触发后自动停止全部交易

---

### 4. 信号质量控制
- **目的**：只执行高质量信号
- **实现**：最小信心度 70%
- **效果**：过滤低质量信号

---

### 5. 连续失败保护
- **目的**：暂停异常交易对
- **实现**：`_symbolFailures` 字典记录失败次数
- **参数**：连续失败3次，暂停10分钟
- **效果**：避免持续亏损
