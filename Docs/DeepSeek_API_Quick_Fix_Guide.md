## ✅ 修复步骤 (10分钟)

### 第1步: 获取新的 API Key (5分钟)

#### 1.1 访问 DeepSeek 官网
```
网址: https://platform.deepseek.com/
```

#### 1.2 注册/登录账号
```
如果没有账号:
1. 点击 "Sign Up" 注册
2. 使用邮箱注册
3. 验证邮箱
4. 完成账号设置

如果已有账号:
1. 点击 "Sign In" 登录
2. 输入邮箱和密码
```

#### 1.3 生成 API Key
```
1. 登录后进入控制台
2. 找到 "API Keys" 或"密钥管理"
3. 点击 "Create new secret key" 或"创建密钥"
4. 给密钥起个名字，如 "币安量化机器人"
5. 点击 "Create" 创建
6. 🔑 复制生成的 API Key（只显示一次！）
   例如: sk-1234567890abcdefghijklmnopqrstuvwxyz
7. 保存到安全的地方（记事本、密码管理器等）
```

**重要提示**:
- ⚠️ API Key 只显示一次，请立即复制保存
- ⚠️ 不要分享给他人
- ⚠️ 如果丢失，需要重新生成

---

### 第2步: 配置 API Key (3分钟)

#### 2.1 打开应用程序
```
1. 启动 币安量化机器人
2. 等待主界面加载完成
```

#### 2.2 进入 API 管理
```
1. 点击左侧导航栏
2. 找到并点击 [🔑 API 管理] 或 [Settings] → [API Manager]
```

#### 2.3 配置 DeepSeek AI
```
1. 在页面中找到 "DeepSeek AI 模型" 部分
   (通常在页面上半部分)

2. 找到 "API Key" 输入框

3. 清空旧的 API Key

4. 粘贴新的 API Key
   - Ctrl+V 或右键粘贴
   - 确保完整粘贴，没有多余空格
   - API Key 通常以 "sk-" 开头

5. 点击 [测试连接] 按钮
   - 等待几秒钟
   - 应该显示 "✅ 连接成功" 或类似提示

6. 点击 [保存] 按钮
   - 确认提示 "配置已保存"
```

**示例配置**:
```
┌─────────────────────────────────────┐
│ DeepSeek AI 模型                     │
├─────────────────────────────────────┤
│ API Key: [sk-1234567890abcdef...]   │
│ Model:   [deepseek-chat]            │
│ Status:  ✅ 已连接                   │
├─────────────────────────────────────┤
│ [测试连接] [保存]                    │
└─────────────────────────────────────┘
```

---

### 第3步: 验证功能 (2分钟)

#### 3.1 打开 AI 智能助手
```
1. 点击左侧导航栏
2. 找到并点击 [🤖 AI智能助手] 或 [AI Assistant]
```

#### 3.2 检查状态
```
界面右上角应该显示:
✅ "AI就绪 ✅" 或 "AI Ready"

如果显示:
❌ "演示模式" 或 "Demo Mode" → 配置未生效，返回第2步
❌ "离线" 或 "Offline" → API Key 可能仍然无效
```

#### 3.3 测试对话
```
1. 在输入框中输入: "你好，请介绍一下你的功能"

2. 点击 [发送] 或按 Enter

3. 等待 AI 响应 (通常 2-5秒)

4. 应该收到 AI 的详细回复

5. 再测试几个问题:
   - "当前市场状况如何？"
   - "请推荐一个交易策略"
   - "我的账户情况怎么样？"
```

## ❌ 常见问题

### Q1: 测试连接失败
```
可能原因:
1. API Key 输入错误
   → 重新复制粘贴，注意去掉空格

2. API Key 已过期
   → 生成新的 API Key

3. 网络连接问题
   → 检查网络，尝试使用VPN

4. DeepSeek 服务异常
   → 访问 status.deepseek.com 查看状态
```

### Q2: 保存后仍显示"演示模式"
```
解决方法:
1. 关闭应用程序
2. 重新启动
3. 再次进入 AI助手
4. 检查状态
```

### Q3: AI 响应错误或超时
```
可能原因:
1. 网络延迟高
   → 检查网络连接

2. API 配额用完
   → 登录 DeepSeek 检查配额

3. 问题太复杂
   → 简化问题重新提问
```

### Q4: API Key 丢失了怎么办？
```
解决方法:
1. 无法找回，只能重新生成
2. 登录 DeepSeek 平台
3. 删除旧的 API Key
4. 创建新的 API Key
5. 重新配置
```
