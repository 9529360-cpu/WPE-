#### 2.1 DecisionEngine（决策引擎）
- **文件**: `Services/AI/DecisionEngine.cs`
- **功能**:
  - ✅ 基于规则的决策系统（5条核心规则）
  - ✅ 回测结果评估（4项指标）

  - ✅ 实盘交易监控（3级警报）
  - ✅ 风险评估（综合评分）
  - ✅ 历史学习优化
- **代码量**: 450+ 行
- **测试**: ✅ 编译通过

**决策规则**:
```
规则1: 高波动保守规则 (优先级1)
规则2: 风险警报规则 (优先级0-最高)
规则3: 策略良好规则 (优先级2)
规则4: 资源不足规则 (优先级1)
规则5: 账户升级规则 (优先级2)
```

**评估标准**:
| 阶段 | 通过条件 |
|------|----------|
| 回测 | 夏普≥1.5, 回撤≤15%, 胜率≥55%, 收益≥20% |
| 模拟 | 盈利≥15%, 回撤≤10%, 胜率≥60%, 天数≥7 |
| 实盘 | 单日亏损≤500, 回撤≤12%, 连亏≤3次 |

## 🔄 工作流程

```
主控制循环:
while (系统运行) {
    1. 收集全系统状态 (市场+账户+策略+风险+资源)
    2. AI决策分析 (规则引擎 + 历史学习)
    3. 执行工作流编排 (动作执行 + 阶段切换)
    4. 学习优化 (记录决策 + 更新知识库)
    5. 等待下一个周期 (5-60秒可调)
}

阶段切换流程:
Idle → Backtest → {通过?} → Simulation → {达标?} → Live
                     ↓ 否               ↓ 否
                 Optimization ←←←←← Backtest
```

## 🚀 使用方式

### 基本使用

```csharp
// 1. 获取中央AI协调器
var coordinator = ServiceLocator.GetAICentralCoordinator();

// 2. 启动主控制循环
await coordinator.StartAsync();

// 3. 查询状态
Console.WriteLine($"当前阶段: {coordinator.CurrentStage.GetDisplayName()}");

// 4. 停止协调器
await coordinator.StopAsync();
```

### 高级使用

```csharp
// 订阅事件
coordinator._eventBus.Subscribe<StageTransitionEvent>(async evt =>
{
    Console.WriteLine($"阶段切换: {evt.FromStage} → {evt.ToStage}");
});

// 获取学习统计
var stats = coordinator._learningModule.GetStatistics();
Console.WriteLine($"成功率: {stats.OverallSuccessRate:P2}");
```

## 🎓 最佳实践

### ✅ 推荐做法

1. **渐进式启动**: 回测 → 模拟 → 实盘
2. **充分测试**: 模拟至少运行7-14天
3. **小资金开始**: 实盘初始资金≤总资金10%
4. **监控日志**: 定期检查 `Logs/app-*.log`
5. **设置警报**: 订阅所有风险事件
6. **定期备份**: 保存学习模块数据

### ❌ 避免做法

1. ❌ 跳过回测直接实盘
2. ❌ 忽略风险警报
3. ❌ 在高波动市场启动实盘
4. ❌ 使用过大杠杆
5. ❌ 不监控系统状态
6. ❌ 在生产环境调试
