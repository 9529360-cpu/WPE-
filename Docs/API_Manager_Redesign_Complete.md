## 🚀 **如何使用**

### **配置 Binance API**

1. **获取 API Key**
   ```
   1. 访问 https://www.binance.com
   2. 登录 → 个人中心 → API 管理
   3. 创建新的 API Key
   4. 勾选「现货和杠杆交易」权限
   5. 复制 API Key 和 Secret Key
   ```

2. **在应用中配置**
   ```
   1. 点击左侧菜单: 🔑 API 管理
   2. 在 Binance 部分粘贴 API Key
   3. 粘贴 Secret Key
   4. 点击 🧪 测试连接
   5. 测试成功后点击 💾 保存配置
   6. 重启应用
   ```

---

### **配置 DeepSeek AI**

1. **获取 API Key**
   ```
   1. 访问 https://platform.deepseek.com
   2. 注册/登录账户
   3. API Keys → 创建新密钥
   4. 复制 API Key
   ```

2. **在应用中配置**
   ```
   1. 点击左侧菜单: 🔑 API 管理
   2. 在 DeepSeek 部分粘贴 API Key
   3. 点击 🧪 测试连接
   4. 测试成功后点击 💾 保存配置
   5. 重启应用
   ```

3. **启用 AI 功能**
   ```
   配置完成后:
   - 🤖 AI智能助手 将使用真实AI
   - 🚀 统一仪表盘 可启动AI交易
   - 🧠 AI模型中心 可管理模型
   ```
